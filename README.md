1) فایل‌ها را در یک ریپوی GitHub آپلود کنید (push).
2) تب Actions > Build APK > پس از پایان، از Artifacts فایل app-debug را دانلود کنید.
3) در www/index.html مقدار ADMIN را به شماره موبایل خودتان تغییر دهید.
4) پنل مدیریت: ۵ بار پشت‌سرهم روی عنوان «بازارچه» (صفحه‌ی ورود) یا «منو» بزنید. ایمیل سازنده کد می‌گیرد (Resend). متغیرهای Worker: ADMIN_EMAIL و RESEND_KEY.
